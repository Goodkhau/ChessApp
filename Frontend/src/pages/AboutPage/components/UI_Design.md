# On UI, UX, React, and Development Challenges

## React

Being my first React project, this has taught me the same lesson C did; React is easy until it isn't. The first few weeks was effectively doing HTML, CSS, and JavaScript in an alternative way and React was just a way to reorganize code I already knew how to write. Then a server entered the picture, and suddenly I was dealing with server state, render cycles, and state management.

## UI/UX

Building the user interface was more difficult than designing and training the machine learning model. From an outside perspective, UI work looks trivial due to how simple the tools are; but that simplicity is deceptive and attribute to the list difficulties of graphical design:

- There's no single "correct" final state to build toward.
- The tools are numerous, and each one solves a slightly different problem but also .
- Compared to well-defined backend systems, UI's open-endedness is exhausting.

Frontend work gets discredited for being "easy" far too often. In practice, the absence of one definitive right answer makes it one of the more demanding parts of the whole project.
